# Organisation profile

This repository holds the front page of [github.com/tuoa-tools](https://github.com/tuoa-tools).
GitHub shows [profile/README.md](profile/README.md) at the top of that page.

GitHub has no folders for an organisation's repositories, so that page does the
grouping: **Tools** are packaged, tested and released; **Prototypes** are
experiments and research notebooks. Add a line there when a repository is
created, and move it when a prototype is promoted to a tool.
